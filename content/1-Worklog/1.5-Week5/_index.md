### Objectives for Week 5:

* Learn about AWS CLI: installation, configuration, and how to manage common AWS services (Amazon S3, Amazon SNS, IAM, VPC, and EC2) through the command line.
* Learn about Amazon DynamoDB: fundamental concepts and how to manage data using the AWS Management Console, AWS CloudShell, and the AWS SDK for Python.

### Expected Outcomes for Week 5:

* Understand what AWS CLI is and how to install and configure it, including Access Key, Secret Access Key, Region, output format, and profiles.
* Be able to create a VPC, Internet Gateway, and Amazon EC2 instance using AWS CLI without relying on the AWS Management Console.
* Understand Amazon DynamoDB and its core concepts, including Primary Keys, Secondary Indexes, naming conventions, data types, read consistency, and read/write capacity modes.
* Gain hands-on experience performing CRUD operations (Create, Read, Update, Delete) on DynamoDB using both the AWS Management Console and AWS CloudShell.
* Be able to create and query Global Secondary Indexes (GSI) to support more flexible data access patterns.
* Understand how to clean up AWS resources after completing hands-on labs to avoid unnecessary charges.
